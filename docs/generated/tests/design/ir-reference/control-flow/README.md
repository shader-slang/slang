# Tests for design/ir-reference/control-flow

## Intent

This bundle is the per-opcode regression suite for the IR control-flow
catalog in
[`docs/generated/design/ir-reference/control-flow.md`](../../../../design/ir-reference/control-flow.md):
the `block` parent, the `param` block-parameter that stands in for SSA
`phi`, the whole `TerminatorInst` family (`return_val`, `yield`,
`unconditionalBranch`, `loop`, `ifElse`, `switch`, `targetSwitch`,
`missingReturn`, `unreachable`, `GenericAsm`), and the non-terminator
group that follows it in the instruction table (`discard`, `Printf`,
`Abort`, `StaticAssert` and the four `Require*` backend hints).

The strategy is one test per catalog row that a natural Slang surface
construct can reach, plus one test per behavioural claim in the
`## Notable opcodes` prose — in particular the two _degenerate_ `ifElse`
shapes (`falseBlock == afterBlock` for an else-less `if`,
`afterBlock == trueBlock` for a loop-condition test), the
predecessor-carries-the-argument encoding of block parameters, the
never-emitted-by-lowering status of `conditionalBranch`, the
reachability obligation that separates `missingReturn` from
`unreachable`, and the conservative side-effect classification that
keeps `discard` and `Printf` alive through DCE.

Every opcode-shape test observes `-target <text-target> -dump-ir -o
/dev/null`, so the assertion is made against the platform-neutral IR the
front end hands off. Conditions, loop predicates and switch scrutinees
are read from `uniform` globals so constant folding cannot collapse the
structured terminator before it is observed, and results are sunk into an
`RWStructuredBuffer` so DCE cannot remove the surrounding blocks. CHECK
patterns are anchored at `func %main` or a user-named callee to cut
through the IR-dump preamble, and cross-operand identities (break label,
merge block, asm-arm block) are asserted with FileCheck captures rather
than by trusting a literal block id. The two claims about diagnostics use
`DIAGNOSTIC_TEST`, and the two DCE-survival claims use `-O3` target text
emit, because neither is visible in an unoptimised IR snapshot.
