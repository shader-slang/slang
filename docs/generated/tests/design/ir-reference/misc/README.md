# Tests for design/ir-reference/misc

## Intent

This bundle exercises the catch-all opcode catalogue in
[misc.md](../../../../design/ir-reference/misc.md) — the opcodes that no
sibling `ir-reference/` page claims. The doc now names a concrete producer
for every row (a `visit*` in `slang-lower-to-ir.cpp`, a core-module
`__intrinsic_op` declaration, a named IR pass, or **no producer at HEAD**),
so the coverage strategy follows that column: every row whose producer is
reachable from portable Slang source gets a test, and the rows produced only
by an IR pass, only by the host/Torch binding path, or by nothing at all are
enumerated under `## Untested claims` with a reason.

Two observation points are used. Opcodes that exist in the platform-neutral
IR are read out of a `-target <text-target> -dump-ir -o /dev/null` snapshot,
with patterns anchored at a user-named function and operands kept symbolic
(behind a generic, or read from a thread id) so neither the constant folder
nor DCE removes the inst before the CHECK sees it. Claims the doc states in
terms of generated code — the work-graph `Barrier` named constants, the
`base.Get(index)` record accessor, the untyped descriptor-heap casts that
"should never reach target code", and the folded `getStringHash` value — are
read out of the final text emit instead, fanned out over every target that
can express them. Value-level claims (which arm a `PackBranch` selects, what
the type predicates answer, whether two hashes agree) are checked with
`COMPARE_COMPUTE -cpu` or `INTERPRET`, because those are questions about a
result rather than about a spelling.

Sibling boundaries: `cross-cutting/ir-instructions` owns the schema, op-flag
and hoistable conventions this page's rows are described with, and
`pipeline/04-ast-to-ir` owns the general AST-node → IR-construct mapping.
This bundle stays on the specific opcodes `misc.md` catalogues, and defers to
[values.md](../../../../design/ir-reference/values.md) for the four
descriptor-_handle_ conversions that page deliberately does not list.
