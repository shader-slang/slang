# Tests for design/ir-reference/resources-and-atomics

## Intent

This bundle exercises the per-opcode catalog in
[`docs/generated/design/ir-reference/resources-and-atomics.md`](../../../../design/ir-reference/resources-and-atomics.md):
the IR opcodes that operate on GPU resources (structured, byte-address,
append/consume buffers; textures and images; descriptor heaps;
cooperative matrix and vector; mesh outputs; raytracing payloads) and
the thirteen members of the `AtomicOperation` group.

The catalog rows make one testable kind of claim — _surface construct X
produces IR opcode Y with operand shape Z_ — so the dominant strategy is
`//TEST:SIMPLE(filecheck=IR):-target spirv-asm -dump-ir -o /dev/null
-stage compute -entry main`, with CHECK patterns anchored at
`func %main` when the opcode belongs to the user body, and matched
globally when the opcode is created inside a core-module function body
that the dump pulls in (`byteAddressBufferLoad`, `byteAddressBufferStore`,
`imageGatherOffset`, `StructuredBufferGetDimensions`). Operands are
derived from `SV_DispatchThreadID` wherever a literal would let the
constant folder collapse the instruction away.

Three groups of claims are not opcode-shape claims and get a different
observation point. Opcodes synthesized by target legalization
(`getOptiXPayloadRegister`, `GetVulkanRayTracingPayloadLocation`,
`ImageTexelPointer`) sit _after_ the `-dump-ir` snapshot, so those tests
pin the backend text instead. Claims about opcodes that a surface does
_not_ produce (`Interlocked*`, `GroupMemoryBarrierWithGroupSync`,
`WaveGetActiveMask`) pin the call form in IR and then the per-target
emitted text, which is what the "wrapper, not an opcode" and "no
producer" notes assert. Finally, `getNaturalStride` and
`getNaturalAlignment` fold to literals before emit, so their values are
verified functionally with `COMPARE_COMPUTE -cpu` and re-checked across
every text-emit target.

Boundary coverage follows the buffer-index and integer axes the catalog
implies: element index `0`, `INT_MAX`, a negative literal, and an
unsigned index for each buffer family; `0`, `INT_MIN`, `INT_MAX`,
`UINT_MAX`, an all-zero mask, and an all-ones mask for the atomic value
operand; and every non-relaxed `IRMemoryOrder` enumerator for the
undeclared trailing order operand.
