# Tests for design/cross-cutting/serialization

## Intent

This bundle exercises the claims in
[`docs/generated/design/cross-cutting/serialization.md`](../../../../design/cross-cutting/serialization.md)
that reach the `slangc` command line. The strategy is the round-trip:
write a `.slang-module` container with `-o`, read it back with
`-dump-module` or `-get-module-info`, and assert that a property the
doc says is carried across the boundary is still there. Four properties
are probed that way — the checked AST/IR of a public symbol, the
parent/child nesting the flat-module read path has to rebuild, the
string payload the flat encoding keeps in side tables, and the raw bits
of numeric and bool constants at their representable extremes. Two more
tests pair a positive and a negative on the container's composition
(`-embed-downstream-ir` adds a SPIR-V blob; without it nothing
downstream is attached), two tests read the version surfaces
(`-get-module-info`, `-get-supported-module-versions`), and three cover
source-location round-tripping, fanning `#line` emission out across
every text-emit target plus SPIR-V debug info, with a
`-line-directive-mode` counterfactual that is itself fanned out across
HLSL, GLSL, Metal and WGSL (SPIR-V ignores the option, and the
SPIR-V debug-info claim names instructions no text emitter has, so both
are recorded as `unsupported-on-target` below rather than forced).

The bundle is small by construction: most of the source doc is about
C++ headers, template patterns, and binary chunk layouts with no CLI
observable, so the `serialize()` pattern, the Fossil memory-mapping
design, the RIFF chunk codes, the flat-table validation asserts, the
recursion budget, and the deprecated repro format all land under
`## Untested claims` instead.
