# Tests for design/name-resolution/overload-resolution

## Intent

This bundle exercises the overload-resolution algorithm described in
[`docs/generated/design/name-resolution/overload-resolution.md`](../../../../design/name-resolution/overload-resolution.md):
the builtin-operator fast path that bypasses the resolver entirely for numeric
scalar / vector / matrix operands, the `TryCheckOverloadCandidate` probe-phase
filter pipeline (arity, fixity, types and coercion, directions, constraints,
visibility), the candidate families the probe phase draws from, the `ForReal`
finalize phase and the focused generic-inference diagnostics it selects, the
`ConversionCost` ranking and the conversions that have no named cost level, the
`CompareOverloadCandidates` tie-breaker (status, cost, lookup-result kind,
implicit-conversion preference, specificity, scope distance), partial generic
application, the general path taken by operators the fast path declines, and the
documented failure modes.

Coverage strategy: one row per documented claim, with positive claims observed
through `//TEST:INTERPRET(filecheck=CHECK):` (an integer tag echoed by `printf`
names the overload that fired, or an overload probe reveals the type an
expression was given) and failure-mode claims pinned with
`//DIAGNOSTIC_TEST:SIMPLE(diag=CHECK):`. Nineteen of the fifty-nine tests are
negative. Boundary probes sit on the same anchor as their parent claim: the
adjacent pairs of the conversion-cost table (150 vs 400, 400 vs 450, 200 vs 300,
32 vs 400), the accumulated-cost sum past the 900 implicit ceiling, the arity
step's lower edge (defaults padding), upper edge (too many) and unbounded edge
(a variadic pack), and the 32-bit/64-bit and signed/unsigned edges of the fast
path's common-type rule.

Overload resolution is fixed at semantic check, so almost every test uses a
single target-independent directive. Two claims are exceptions and say so: the
GLSL-operator-scope carve-out needs `-allow-glsl` and therefore runs as
`COMPARE_COMPUTE -cpu`, and the parameter-group auto-dereference cost needs a
`ConstantBuffer` global that the interpreter cannot host, so it is observed in
emitted HLSL.
