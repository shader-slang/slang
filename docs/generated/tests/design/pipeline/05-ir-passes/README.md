# Tests for design/pipeline/05-ir-passes

## Intent

This bundle exercises the IR-pass catalog in
[`docs/generated/design/pipeline/05-ir-passes.md`](../../../../design/pipeline/05-ir-passes.md):
the categorized inventory of the `slang-ir-*.cpp` transformations that run
between AST -> IR lowering and code emission, orchestrated by
`linkAndOptimizeIR` in `slang-emit.cpp`. Every test anchors on one of the
doc's category headings (`#linking-and-validation`,
`#ssa-construction-and-basic-cleanup`, `#specialization-and-generics`,
`#differentiation-autodiff`, `#type-and-value-legalization`,
`#inlining-and-call-graph`, `#entry-point-and-parameter-handling`,
`#layout-and-binding`, `#loop-transformations`, `#target-specific-lowering`)
or on the two orchestration sections (`#how-the-passes-are-ordered` and the
`#phase-skeleton-of-linkandoptimizeir` table) and confirms one observable
consequence of a named pass.

Three modes of observation are used:

- **`-dump-ir-before` / `-dump-ir-after <pass>`** with FileCheck against the
  `### BEFORE <pass>:` / `### AFTER <pass>:` headers. Used for the
  orchestration claims (`specializeModule`, `simplifyIR`, `eliminatePhis`,
  `eliminateDeadCode`, `performForceInlining`,
  `lowerBufferElementTypeToStorageType`) where the only surface is the
  dump stream.
- **Multi-target `SIMPLE` emit**, one `//TEST:SIMPLE(filecheck=<NAME>)` per
  text-emit target the pass is observable on, with a per-target CHECK
  prefix. This carries the bulk of the legalization / lowering coverage.
- **`DIAGNOSTIC_TEST` / diagnostic-pinning `SIMPLE`** for the validation
  passes whose surface is a diagnostic: check-recursion, missing-return,
  check-optional-none-usage, operator-shift-overflow,
  check-differentiability, mesh-output reads, and the late
  `validateVectorsAndMatrices` matrix-limit check.

This regeneration realigns the bundle to the current revision of the source
doc, which grew a `#phase-skeleton-of-linkandoptimizeir` region table and
reworded several pass rows. New coverage was added for the claims that
rewording introduced: the bool-switch -> integer-switch rewrite that the
GLSL-legalize row now names for GLSL / SPIR-V / WGSL; the two documented

specialize-arrays tests that were written against the old "specializes

generic-substitution claim they actually observe, and a new test covers the
reworded row.

`size_cap_files` is 150; the bundle has 120 test files.
