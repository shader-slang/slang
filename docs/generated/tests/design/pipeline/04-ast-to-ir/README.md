# Tests for design/pipeline/04-ast-to-ir

## Intent

This bundle exercises the AST → IR lowering stage described in
[`docs/generated/design/pipeline/04-ast-to-ir.md`](../../../../design/pipeline/04-ast-to-ir.md).
Coverage follows the doc's own decomposition:

- the **AST-family → IR-construct table** (`FuncDecl` → `IRFunc` with
  `IRBlock`s, `VarDecl` → `IRVar` / `global_param`, `StructDecl` →
  `IRStructType` with `field(...)` children, `InterfaceDecl` →
  `IRInterfaceType` with requirement-key entries, `GenericDecl` →
  `IRGeneric`, structured branches → `ifElse` / `loop` / `switch` with
  an explicit join operand, `ReturnStmt` → `return_val`, `InvokeExpr` →
  `call`, `MemberExpr` → `get_field` / `get_field_addr`, `LiteralExpr`
  → constant inst, `CastOptionalExpr` → an if/else diamond around a
  temporary, `WitnessTable` → `IRWitnessTable`), plus the `(void)expr`
  carve-out that yields the canonical void constant instead of a
  cast inst;
- the **`BuiltinOperatorExpr` fast path** — recognized scalar / vector /
  matrix operators emitted as one pure inst without callable
  resolution, with `%` selecting `frem` vs `irem` by element type and
  `?:` / `&&` / `||` carved out to their control-flow paths;
- the **compound `LoweredValInfo` flavors** that stay symbolic until a
  use site reads or writes them (swizzled l-value, accessor-backed
  storage);
- **generics and existentials** — specialization is deferred to a later
  IR pass, so a call site is `call specialize(%generic, T)(...)`; a
  generic interface requirement keeps its own generic parameters in the
  witness-table entry and its use site becomes
  `specialize(lookupWitness(...), ...)`; requirement keys are per-decl
  `key` insts or hoistable `builtinRequirementKey`s; associated-type
  bounds are relocated to interface-level requirement entries;
  differentiability arrives as a synthesized conformance;
- **module-level and entry-point-scoped outputs** — the `entryPoint`
  decoration, work-graph node attributes (launch mode kept as a string
  literal), the lifted shader-64-bit-indexing decoration;
- **debug-info gating** — synthesized initializers get no debug lines,
  user-written `__init`s keep theirs and name the object `this`;
- **lowering-time diagnostics** — the unreachable-code warning for
  statements ahead of a switch's first `case` label.

The primary observation mechanism is
`-target spirv-asm -dump-ir -o /dev/null` followed by FileCheck against
the IR dump, anchored on a user-named function (`func %main` or a
helper) to cut through the preamble of capability sets, core-module
imports, and differentiation glue. Almost every claim here is a
target-independent IR-shape claim, so the bundle uses a single
`-dump-ir` directive per test rather than a per-target emission
fan-out; the one exception is the work-graph node-attribute test, which
must compile for a target that admits node entry points and therefore
uses `-target hlsl`.

Cross-cutting decoration / opcode catalog coverage (`entryPoint`,
`nameHint`, the per-opcode catalog shape) lives in
[`cross-cutting/ir-instructions`](../../cross-cutting/ir-instructions/);
this bundle anchors on the AST side of the mapping ("which AST node
lowers to which IR construct"). The mandatory pass sequence that runs
after lowering — including the early-inlining / prelinking of imported
`[unsafeForceInlineEarly]` bodies — belongs to
[`pipeline/04b-pre-link-passes`](../04b-pre-link-passes/).
