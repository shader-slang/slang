# Tests for design/ast-reference/base

## Intent

This bundle exercises the abstract AST roots described in
[`docs/generated/design/ast-reference/base.md`](../../../../design/ast-reference/base.md):
`NodeBase`, `SyntaxNodeBase`, `SyntaxNode`, `Modifier`,
`ModifiableSyntaxNode`, `DeclBase`, `Decl`, `Stmt`, `Expr`, `Val`,
`Type`, `DeclRefBase`, and the `Scope` helper.

`slangc` never exposes its AST, so the bundle is built on a single
translation rule: a claim is testable only when program text would
behave differently if the claim were false. Each root class is probed
through the one thing it contributes to the front end — a name plus a
parent for `Decl`, a checked type for `Expr`, a source location for
`SyntaxNodeBase`, a modifier list for `ModifiableSyntaxNode`,
deduplication for `Val`, substitutions for `DeclRefBase`, an owned
lookup scope for `Scope`. Coverage strategy is one functional
observation per such contribution, plus a negative/diagnostic probe
wherever the class has a natural failure mode (unresolvable name,
r-value assignment, misplaced attribute, statement out of context).
Every test is target-independent — these are parser and checker
behaviours that complete before any back end runs — so the bundle uses
`//TEST:INTERPRET` for value observations and
`//DIAGNOSTIC_TEST:SIMPLE` for rejection claims, with no per-target
fan-out.

Realignment notes for this revision of the source doc, which moved
several claims:

- `SyntaxNodeBase` has no heading of its own; its `loc: SourceLoc`
  claim lives under `### SyntaxNode (SyntaxNodeBase)`
  (`#syntaxnode-syntaxnodebase`), and `DeclRefBase` is described inside
  `### Val (NodeBase)` (`#val-nodebase`). Tests anchor accordingly.
- `### DeclBase (ModifiableSyntaxNode)` now states that the parser
  produces a group node "when one piece of syntax declares several
  names", which is directly observable; the bundle gained two tests
  for it.
- `### Stmt (ModifiableSyntaxNode)` now states that deriving from
  `ModifiableSyntaxNode` is what gives a statement a source location
  _and_ a modifiers list; the bundle gained a statement-location test
  and a multiple-modifiers-on-one-statement test.
- The `Scope` bullet under `## Root hierarchy` changed from "does not
  appear in the parsed AST" to "created during parsing to support
  lookup and attached to container declarations", which made
  container-scoped unqualified lookup a testable claim.

The bundle is 23 files, above the 6-15 range the co-located
`_prompt.md` suggests. The range was written against an earlier, terser
revision of the doc; this revision states more per-class claims (the
`DeclBase` group node, the `Stmt` location, the `Scope` attachment, the
`IntVal`/`Witness` members of the `Val` family, the l-value component
of the type an `Expr` carries), and each added file covers one of them.
The file count remains well under the manifest's `size_cap_files: 30`.
