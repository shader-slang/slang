# Tests for coverage/check-decl

White-box characterization tests targeting under-exercised declaration-checking
branches in `source/slang/slang-check-decl.cpp` (75.01% line-covered by the

## Intent

Drive diverse declaration forms and documented error/diagnostic paths through
`slangc`/`slangi` and pin the observed result. Error paths use `//DIAGNOSTIC_TEST`
(they validate locally even without FileCheck, and are exhaustive by default, so
they also pin the _absence_ of diagnostics on the accepted declarations in the
same file); clean codegen forms (property, subscript, extension method, texture
format inference) use `//TEST:SIMPLE` with FileCheck; value-level positives (enum
tag values, integer generic value-parameter specialization, conjunction
constraints) use `//TEST:INTERPRET` so the interpreter validates them locally.
Every diagnostic message and code below was copied verbatim from a real `slangc`
run.

The 2026-08-05 pass added coverage for four previously untouched clusters:
`dyn interface` validation (which only runs under `-std 2026`), the capability
propagation/provenance visitor, resource-declaration checks (`register()` class
letters, image-format inference, unsized arrays in constant buffers), and a few
isolated declaration-checking helpers.
