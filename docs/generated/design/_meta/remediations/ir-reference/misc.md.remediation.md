# Remediation report for ir-reference/misc.md

## Summary

Six findings were fixed and one was rejected as out of scope, so the document
was edited and `mark-fresh` is needed. Both critical findings were confirmed
against the source: the type predicates fold on the unwrapped element type (so
`IsVector` folds to `false` for every concrete type), and the barrier IR carries
a folded numeric bitmask whose C++ `static_assert`s pin only the C++ side. All
16 retired `(synthesized)` origin cells were converted — 15 to named producers
and `nop` to **no producer at HEAD** — so no `(synthesized)` origin remains on
this page. The 12 hand-written wrappers are now marked with `‡`, three operand
cells were restored to the Lua schema, and the obsolete first coverage gap was
deleted.
