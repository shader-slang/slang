# HGVM interop examples

- [Python value interop](py/README.md): scalars, Point values, shared class references, and structs owning GPU buffers.
- [C++ hello world](cpp/README.md): a complete native host with CMake include/link instructions.
- [Browser JavaScript](js/README.md): JSPI calls, structs owning GPU buffers, and a WebGPU Canvas window.

Each sample keeps its Slang sources beside its host code.
